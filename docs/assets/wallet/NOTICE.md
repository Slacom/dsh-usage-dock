# 钱包图标素材来源与许可

| 文件 | 来源 | 许可 |
|---|---|---|
| `../../icon.svg` | Material Symbols `wallet`（经 Iconify 导出，24×24 路径放大到 36×36） | Apache-2.0（Google） |
| `../../icon-outline.svg` | 本仓库按 DSH Go 胶囊钱包图标的观感自绘 | MIT（dsh-usage-dock） |
| `wallet-material-symbols-filled.svg` | Material Symbols `wallet` | Apache-2.0（Google） |
| `wallet-lucide-outline.svg` | [Lucide `wallet`](https://lucide.dev/icons/wallet) | ISC（Lucide Contributors） |
| `wallet-outline-36.svg` | 同 `icon-outline.svg` | MIT（dsh-usage-dock） |

说明：DSH Go App 的胶囊/面板图标是 **App 内置图标名**（manifest 里只写 `"icon": "wallet"`），
插件包本身不包含该图形资源；以上文件是给桌面端设置主页/插件入口使用的可复用素材，视觉为近似实现。
