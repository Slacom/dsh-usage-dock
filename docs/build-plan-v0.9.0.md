## 2. 渠道退场与自定义余额主线

0.9.0 的新主线按 [详细设计](custom-balance-v0.9.0.md) C0→C5 推进：先冻结通用契约，再处理三渠道退场、设置/schema/秘密存储、通用请求、动态胶囊/卡片及回归。此主线不依赖 tools 服务，可与方向 6 分开验收。

退场 id 是 `kimi-code`、`glm-zhipu`、`glm-zai`，不是 OpenCode。双端注册表、设置、排序、详情和工具同步退出；建议 Host 停止轮询隐藏渠道，兼容旧配置但不删除模型凭据或强制清理 profile。保留 parser 作历史资料，不修 Kimi 口径/ratio-pool。旧工具显式请求建议回 unknown + `retired-channel`，不取数、不参与策略。

自定义区在内置设置之后、统一保存/放弃之前。最小四项为名称、余额 API URL、Key、JSON 键路径；Key 留空可复用用户明确选定的模型凭据，不能只凭厂商名称猜 Key。拟议额外项是币种、凭据引用及可选固定“余额键 − 扣减键”；需在 C0 冻结，不能把 OpenRouter 的累计充值误当剩余。仅 GET/Bearer/JSON 类余额接口，不做 Cookie/OAuth、签名、套餐额度或厂商特例。

成功自定义条目按余额逐行展示；网络/429/5xx 等暂时失败保留该条成功值并灰化，连续第 8 次纯错误；明确鉴权/配置错误立即提示，恢复清零。修改 URL/Key/引用/路径/币种、停用或删除必须使旧值、在途响应和缓存失效。详见设计中的错误分类与安全验收。

## 4. 工具契约与渠道安排

建议首轮核验 Codex、DeepSeek、MiMo、WorkBuddy、WorkBuddy AI；OpenCode 在窗口用途核实后扩展，GLM 智谱/Z.AI 与 Kimi 已纳入退场，不再安排工具适配。自定义余额条目由通用投影扩展为 kind=balance，默认只读可查询，策略资格另行明确授权，不能默认套 UI 告警。参数接受活动内置与稳定自定义 id；查询范围为“支持白名单 ∩ 当前已启用渠道 ∩ 用户请求”。未知 id、三个退场 id 和被删除的 custom id 必须区分，不复活旧条目。

- 每渠道多个窗口，保留 rolling/weekly/monthly 及用途 scope；不把 MCP 月池当模型生成额度。
- `kind` 区分 balance/quota/credits；数值带币种/积分单位；只有比例时不反推绝对额度。
- Codex 保持剩余比例；其他渠道核实后显式标口径，不能把所有百分数当剩余。
- 缺凭据、登录失效、未安装、传输失败与耗尽不同；零余额、未知金额和 unlimited 也不同。
- `fetchedAt` 是成功采集时间，缓存命中不改时间；TTL 内复用不等于 stale；错误不得悄悄复用旧成功数据劝停。
- 只输出白名单数字、固定状态码与时间；不透传 Key/Cookie/token、账号、路径、套餐自由文本或上游错误原文。
- 模型策略阈值与 UI 告警分开授权；示例 20%/50% 不是已确认默认值。
- 不做所有渠道“最低余额”自动停工，不猜当前模型对应计费账户；显式选择策略关注渠道。

## 5. 缓存、可选服务与 0.8.5 兼容

通过 `ctx.get('tools')` / `ctx.get('systemPrompt')` 取可选服务，兼容 undefined/null/throw；不 import 插件目录无法解析的宿主工具包，不加硬 inject。真实工具的执行参数、output.schema/render、disposer 仍须核验；冒烟若需改已安装 profile，应另行取得授权。

工具侧缓存只存成功数据，TTL 建议 30 秒，按渠道与配置/凭据代次隔离；同代 single-flight，失败 finally 清理，旧代迟到不得回填新代。首版不做隐式 stale-if-error。

Web 仍即时取数；不改变 focus/visibilitychange/展开强刷，不把浏览器灰化旧值用于模型决策。保留 0.8.5 的 WorkBuddy 固定前缀分类、暂时错误灰化、明确语义错误透传、失败阈值 8、Host 35s / Client 40s。8 次失败不是严格“四分钟”：慢请求、跳过轮询、手动强刷会改变实际耗时。

## 6. 策略行为与发布边界

- `quotaPolicyEnabled` 默认 false，关注渠道/阈值显式设置，字段 `.volatile()`。
- 未配置、unknown/error/stale、暂缓或无法映射渠道只说明情况，不给“必须停工”结论。
- 建议收尾：当前最小工作单元 → 检查变更 → 必要测试 → 保存进度与交接 → 收尾。
- 提示词不能保证模型必调用、绝对不超额或硬性停机；不自动切模型、不杀宿主、不重启。
- **0.8.5 仅本地定档：不 push、不推标签、不创建 GitHub Release、不 npm publish。**本地已有标签不等于公开发布。
- 后续试装通过也不自动解除当前“不推送”决定；必须等待用户明确开启发布流程。
