# dsh-usage-dock v0.8.4

> 0.8.3 已正式发布（GitHub Release + npm）。本版只有一个修复：**胶囊不再盖住 DSH 官方通知卡**。

## 修复：官方通知卡与胶囊「文字重合」

**现象**（用户 2026-10-17 截图）：DSH 在左下角弹出官方通知卡（「模型已更新 / DeepSeek V4.1-Flash
模型已更新 …」）时，通知卡的正文与胶囊的五行状态文字叠在一起，像两段文字互相穿透。

**定位（像素级证据，不靠猜）**：

| 采样点 | 结果 | 结论 |
| --- | --- | --- |
| 通知卡内边距 | RGB (255,255,255) / (254,254,254) | 卡片底色**接近不透明**（其后方是 249 的侧栏底色） |
| 通知卡整块的暗像素 | (15,17,21)，与 `label-primary` 令牌一致 | 卡片自身文字是实色，没有被别的东西压住 |
| 胶囊数值列 | (15,17,21) 实色 | 我们的文字是**全对比**画在卡片白底之上 → 胶囊在上、卡片在下 |
| 胶囊名称列 | L≈100 | 与 `label-secondary`（次要灰色）一致，不是被蒙层压亮的结果 |

**根因**：`rootStyle` 里的 `zIndex: 1000`——它从 0.2.1-slacom.1 第一版就在，本意是让详情浮层
压在侧栏内容之上；副作用是把整个胶囊抬到了官方通知卡（portal 挂在页面尾部）**上面**。
胶囊背景又是透明的（对齐侧栏按钮的设计），于是卡片正文从我们文字的空隙里透出来。

**修复**：去掉 `zIndex`，回到默认的 `auto`，让 DOM 顺序决定绘制次序——后挂载的 portal（官方通知、
其它浮层）自然盖住胶囊。附带核查：

- 侧栏 CSS 里只有顶部固定按钮用 `z-index:30`，与底部胶囊/面板位置不重叠；
- 侧栏内容都是静态流，我们的根节点仍是 `position: relative`、面板仍是 `position: absolute`，
  仍绘制在静态内容之上，详情面板不会被侧栏列表压住；
- 通知卡消失后胶囊照常可见，交互不受影响。

**测试**：`test-footer-row.mjs` 11 → **12** 项，新增 T12：

- 胶囊根节点**不得**带正 `z-index`（允许 `undefined` / `'auto'`）；
- 根节点仍 `position: relative`、面板仍 `position: absolute`（防止有人为了修层级把面板改成静态）。

**验证状态**：官方通知内容由服务端下发，本地无法主动复现；发布前由用户真机确认——**DSH 的
「安装并重启」提示卡已经能完整盖住胶囊**（同属页尾挂载的浮层，验证的正是这条层叠路径）。
若将来出现仍互相穿透的浮层（先于我们挂载），备选方案已记入 roadmap：用
`document.elementFromPoint()` 检测胶囊所在位置是否被外部元素覆盖，覆盖时暂时隐藏我们的文字
（不依赖任何 z-index 假设）。

## 安装

0.8.4 已发布到 **npm**（`latest`）与 **GitHub Release**：

1. **npm（推荐）**：`dsh plugin --profile <profile> add dsh-usage-dock@0.8.4`，
   或在「设置 → 插件 → 添加插件」里填 `dsh-usage-dock`；
2. **Release 附件直链**：`https://github.com/Slacom/dsh-usage-dock/releases/download/v0.8.4/dsh-usage-dock-0.8.4.tgz`
3. **Git 仓库**：`https://github.com/Slacom/dsh-usage-dock`（装主干最新提交）

已安装旧版的需**先卸载再安装**（DSH 对第三方插件不支持原地升级）；卸载不会删除渠道配置。
