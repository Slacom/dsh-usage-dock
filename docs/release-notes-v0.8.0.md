## 1. 取数失败保留旧值 + 灰字弱化（roadmap 方向 3）

**旧行为**：任何一轮取数失败，该渠道立即整行换成「获取失败」——VPN + 高负载时
瞬时抖动会被放大成反复闪烁。

**新行为**：

- 失败时**保留上一次成功值**继续显示，数值改用**灰色弱化**（状态灯同步转灰）；
- **连续 2 轮失败**（约 60 秒）才显示「获取失败」；恢复成功后立即回到正常显示；
- 按用户定稿：不加「更新于 HH:mm」标注，只用灰字表达「数据可能已过期」；
- 语义错误（未配置 Key 等）不参与降级，立即透传原因——这类错误不会自愈，
  拿旧值顶着会掩盖配置问题。

**配套——轮询防卡死**（0.7.x 的真实风险）：客户端 `fetch` 原先没有超时且
`inFlight` 只在请求 settle 时复位，请求一旦挂起，30 秒轮询**永久停摆**。
现在：AbortController 20 秒超时；请求 settle（成功/失败/超时/被作废）后必然
复位；Host 端 `deepseekAccount.getBalance` 也包了 20 秒超时，不再拖死
`Promise.all` 里的其他渠道。

**配套——超时放宽**：三后端（原生 fetch / Python shim / curl）单请求超时
10s → 20s，移动端（无兜底后端）慢网络下不再被过早判死。

## 2. 余额向下取整到分（roadmap 方向 2 附带）

0.7.x 的 `toFixed(2)` 是四舍五入：真实余额 34.31662152 显示 34.32，而 DSH
设置页截断成 34.31——「胶囊总比设置页多一分」。现在改为**向下取整到分**，
与设置页截断语义一致（DeepSeek 与小米 MiMo 均适用）。

## 3. 点击展开详情面板立即刷新 + 充值后余额同步（roadmap 方向 2）

- **点开即刷**：点击胶囊展开详情面板时，立即作废 in-flight 请求并强拉一次
  最新数据（对齐 dsh-cost-meter 的「点击即刷新」交互）；刷新期间面板照常
  显示旧值，不会闪空白。
- **focus 刷新**：窗口重新聚焦 / 标签页重新可见时也强拉一次——桌面端充值页
  是覆盖窗口的原生视图，支付完成返回时窗口重新聚焦，余额随即同步（旧版要
  等最多 30 秒）。

## 4. DeepSeek 充值入口（roadmap 方向 1）

详情面板 DeepSeek 余额行右侧新增「充值」按钮：

- 点击打开 DSH **原生充值页**（与「设置 → 账号与余额」的充值按钮同一个
  `top-up` 页面；经 preload 暴露的 `dshPlatform.open` 桥打开，自带返回栏）；
- 仅在**账号登录**（`via === "account"`）且**桌面端**（存在原生桥）时渲染；
  API Key 模式没有账号充值语义；浏览器 / 移动端没有原生桥，按钮不显示
  （官方此时回退外链，本插件不做外链回退）。

## 5. DeepSeek 峰谷价时间条（classic 样式）

DeepSeek API 实行峰谷两档计价（峰时段价格为空闲时段两倍）。详情面板的
DeepSeek 区块（余额行下方）现在渲染一条 **classic 峰谷时间条**（样式照抄
dsh-cost-meter）：

- 8px 分段圆角条：**橙色 = 峰时段**（北京时间 09:00–12:00、14:00–18:00），
  **蓝色 = 空闲时段**；带橙描边三角指针标记当前时刻位置；
- 下一行胶囊徽章：「高峰时段 / 空闲时段 / 周末 / 假期 · 约 N 后进入高峰/空闲」；
- **周末与法定假日全天空闲价**（假日表硬编码 2026 年国务院安排，随版本更新）；
- 仅**账号登录**时显示（host 在响应里附带算好的相位；API Key 模式没有峰谷
  语义）；纯本地时间计算，不增加任何网络请求。

## 6. 新渠道：小米 MiMo API 余额

在侧栏显示小米 MiMo 开放平台的**账户余额**（不做套餐积分额度）：

- 数据：控制台 `GET /api/v1/balance`（与控制台「账户余额」页同源），显示
  总额；详情面板另附**现金余额 / 赠送余额**两行明细；币种随账号返回
  （CNY→¥、USD→$）；
- 鉴权：**小米开放平台控制台 Cookie**（登录 platform.xiaomimimo.com → F12 →
  网络 → 任一请求 → 复制请求头完整 cookie 值，需含 `userId` 与
  `serviceToken` 字段）；设置页新增 Cookie 输入框与说明。登录态过期会给出
  「重新复制 Cookie」提示；`tp-*`/`ttp-*` 形态的专用 Key 无余额端点，不支持；
- **余额警告阈值**：默认 10 元（0 = 不警告），低于阈值状态灯转红，与
  DeepSeek 同款机制。

## 升级方式

```powershell
dsh plugin --profile <你的 profile> add dsh-usage-dock@0.8.0
```

安装后**重启 DSH**，浏览器硬刷新（Ctrl+Shift+R）。要用小米 MiMo 渠道，到
「设置 → 内置插件 → Usage Dock」里填控制台 Cookie（获取方法见上）。
